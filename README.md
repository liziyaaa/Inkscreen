这是一个围绕“信息放在眼前，少一点反复打开手机”做出来的桌面墨水屏项目。已有实物用于展示内容，电路板与屏幕组成主体；课程、日程、训练安排与状态看板等信息，可以用清晰的黑白页面长期呈现。

仓库同时收录 **InkScreen Studio 通用墨水屏界面编辑工具**：在浏览器中编辑模板、调整目标像素尺寸、预览黑白效果，导出 PNG、原始位图与结构化内容包，供不同显示设备适配使用。

摆件实物与编辑器是两部分独立工作。现有实物页面并非由该编辑器生成；工具提供可复用的内容制作路径，接入具体设备时仍需对齐分辨率、位图格式与固件接口。

## 实物与演示

### 实机动态演示

项目保留有真实设备运行的 GIF，作为屏幕实际展示与交互效果的记录。实机表现以这类现场演示为准，不能用外观渲染替代。

### 电路板与屏幕结构

电路板渲染展示已有实物的板级外观与装配关系：屏幕作为主要显示面，电路板位于下方，通过支撑件固定形成桌面摆件主体。它是实物结构对应的设计渲染，不是实物照片。

### 三种功能展示

| 页面 | 展示内容 | 素材性质 |
|---|---|---|
| 课程 / 日程 | 课程名称、时间与教室，集中呈现当天安排 | 白色微透塑料外壳与内部电路板的功能渲染 |
| AI 额度看板 | 多个服务的剩余额度、进度与重置时间 | 页面内容与外观渲染，不代表已接入实时额度接口 |
| 训练清单 | 动作、组数、次数、休息时间与勾选区域 | 页面内容与外观渲染，不代表实机具有触控或自动训练记录能力 |

外壳渲染在已有电路板结构上加入白色微透塑料外壳，用于展示整机外观与信息排版。三张功能图不作为外壳已制造、对应数据服务已接通或功能已完成联调的证明。

五份原始素材的归档清单见 [演示素材说明](assets/README.md)。目前媒体文件尚待归档，此处暂不放置不可用的图片链接。

## 这个项目里值得折腾的地方

- **信息常驻在桌面。** 将课程、待办或训练清单放到固定显示面，抬头就能查看，适合变化频率较低的信息。
- **围绕低功耗组织更新。** 墨水屏保持画面与整机持续耗电是两回事，电源、控制与刷新策略需要一起考虑；本项目以超低功耗为设计目标，具体表现仍以测量为准。
- **电路与外观一起考虑。** 板级结构、屏幕显示面、支撑件和外壳展示共同组成整机方案。
- **内容制作可以独立复用。** 编辑器面向可配置像素尺寸与黑白位图，不将工具绑定到某一种主控或屏幕对角线尺寸。
- **导出内容，也保留结构。** PNG 便于查看，BIN 便于设备加载，JSON 保留页面参数与位图，Manifest 为设备侧按需更新提供约定。
- **展示与适配分开推进。** 实物运行记录、外观渲染和工具能力分别说明，后续可以逐步补齐硬件文件、固件接入和测量结果。

## 内容如何显示到设备上

1. **准备信息。** 整理课程、清单、状态指标或图片，确定页面内容与更新频率。
2. **生成显示内容。** 可以使用已有固件的绘图流程，也可以用通用编辑器预览并导出目标分辨率位图。
3. **适配设备接口。** 对齐像素排列、黑白极性、每行字节数、方向及刷新方式；由设备侧实现读取或传输。
4. **刷新并管理功耗。** 按实际需求更新画面，再控制屏幕驱动、主控与外围电路的工作状态。

现有实物沿用其原有界面制作流程。编辑器是可供后续适配的另一条内容生成路径，目前不将两者描述为已经完成端到端联调。

## 通用界面工具

**[在线打开 InkScreen Studio](https://liziyaaa.github.io/Inkscreen/tools/inkscreen-studio/)**

编辑器以 HTML、CSS 和原生 JavaScript 实现，不需要构建工具。原仓库根地址仍保留跳转入口，编辑状态继续使用同源浏览器本机存储。

| 能力 | 当前实现 |
|---|---|
| 页面管理 | 新增、复制、删除页面，修改标题与页脚 |
| 内容模板 | 今日看板、课程 / 日程、效率、氛围、天气、专注、倒计时、习惯、便签、图片、提醒、设备状态与单词卡 |
| 像素尺寸 | 多个像素预设与自定义宽高，当前单边范围为 64–1200 像素 |
| 图像处理 | 图片导入、阈值二值化、抖动与反相 |
| 导出 | PNG、当前页 BIN、完整 JSON 内容包与 Manifest |
| 设备传输 | 浏览器侧 BLE 与局域网 HTTP 发送实现，需要接收端实现匹配协议 |
| 本机使用 | 浏览器保存编辑状态，Service Worker 提供离线缓存 |

编辑器中的数据是可编辑的页面参数。天气、额度、设备状态等页面不会因显示了数值就自动连接相应服务；自动数据更新需要另行接入数据源。

### 位图与设备适配

当前导出使用 `raw-1bpp-msb`：逐行排列，每字节高位在前，黑点为 `1`、白点为 `0`，每行占 `ceil(width / 8)` 字节。位图总字节数为：

`ceil(width / 8) × height`

这些是工具的内容格式约定。具体显示驱动可能需要反相、旋转、改变位序或转换缓冲区，不能直接把“能导出”视作“任意屏幕即插即用”。完整约定见 [内容包协议](docs/content-package-v1.md)。

## 快速上手

### 1. 制作一张页面

打开在线编辑器，先按目标设备设置像素宽高，再选择模板、填写参数或导入图片。查看预览后调整阈值、抖动与反相，检查小字、细线和黑白对比。

### 2. 导出并接入设备

- **先看排版：** 导出 PNG，确认内容完整与字体可读。
- **设备已有位图加载流程：** 导出当前 BIN，按目标驱动的缓冲区规则转换或加载。
- **需要保存页面参数：** 导出完整 JSON 内容包。
- **需要按清单更新：** 导出 Manifest，并实现设备侧获取、CRC 比较、位图下载与刷新。

BLE 与 Wi-Fi 发送仅适用于实现了对应接收协议的设备。浏览器兼容性、HTTPS 与局域网请求策略可能影响连接；使用前请阅读 [工具说明](tools/inkscreen-studio/README.md)。

### 3. 本地运行

下载或克隆仓库后，在仓库根目录运行：

```bash
git clone https://github.com/liziyaaa/Inkscreen.git
cd Inkscreen
python -m http.server 5173
```

打开 [本地编辑器](http://127.0.0.1:5173/tools/inkscreen-studio/)。线上部署使用 HTTPS，以支持相关浏览器能力。
