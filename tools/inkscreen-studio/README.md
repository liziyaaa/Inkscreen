# InkScreen Studio · 通用墨水屏界面编辑器

浏览器中的黑白墨水屏内容制作工具。支持模板参数、图片、可配置像素尺寸、黑白预览和文件导出，面向能够适配相应位图格式的显示设备。

**[在线打开](https://liziyaaa.github.io/Inkscreen/tools/inkscreen-studio/)** · [回到项目说明](../../README.md)

## 与摆件项目的关系

工具与已有墨水屏摆件独立开发。已有实物页面不是由本工具生成的；将导出内容用于该实物，需要验证目标分辨率、显示缓冲区、传输协议与刷新流程。

## 使用

1. 设置目标宽高。预设仅按像素标注，不对应特定硬件；自定义单边范围为 64–1200 像素。
2. 添加页面，选择模板，编辑参数、批量文本、标题或页脚；图片模板支持导入图片。
3. 调整阈值二值化、抖动与反相，查看黑白预览。
4. 导出 PNG 查看排版，或导出 BIN、JSON 内容包及 Manifest 供设备侧使用。

页面编辑状态保存在同源浏览器 localStorage。目录迁移保留原缓存键，不会主动清除已有编辑内容；换设备或清理浏览器数据前，请导出文件。

## 输出

| 文件 | 用途 |
|---|---|
| PNG | 排版查看与图片流程 |
| 当前 BIN | 当前页面的 `raw-1bpp-msb` 位图 |
| JSON | `inkscreen.package.v1` 完整页面参数与 base64 位图 |
| Manifest | `inkscreen.manifest.v1` 页面 URL、字节数与 CRC32 等清单 |

位图逐行排列、高位在前，黑点为 1；每行字节数为 `ceil(width / 8)`。需要按目标驱动转换位序、方向或黑白极性时，在接收端实现转换。完整格式见 [协议](../../docs/content-package-v1.md)。

## 设备连接

浏览器侧已实现 BLE 连接、发送内容包 / 当前位图、写入 Wi-Fi 配置，以及 HTTP 推送。接收设备必须实现匹配服务、特征、命令和接口；仓库当前不包含对应硬件固件，不能据按钮存在判断设备兼容。

BLE 使用 Web Bluetooth。浏览器需支持该 API，并运行在允许的安全上下文；不支持时仍可使用编辑与导出。Wi-Fi 推送还受跨域、混合内容及局域网访问策略影响，应在目标浏览器和网络实际验证。

Manifest 描述设备拉取更新的约定，网页本身不会替代设备实现定时唤醒、下载或刷新，也不会自动读取天气或第三方账户额度。

## 本地运行

在仓库根目录启动静态服务器：

```bash
python -m http.server 5173
```

打开 `http://127.0.0.1:5173/tools/inkscreen-studio/`。直接打开仓库根网址会跳转到此目录。
